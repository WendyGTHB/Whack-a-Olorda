# Whack-a-Olorda

Whack-a-Olorda és un videojoc desenvolupat com a treball de recerca de primer de batxillerat. El projecte consisteix en una versió senzilla del clàssic Whack-a-Mole, creada amb HTML, CSS, JavaScript i Phaser 3, amb l’objectiu d’explorar l’ús d’eines d’intel·ligència artificial com a suport en el desenvolupament de software.

## Descripció del projecte

Aquest projecte forma part d’un treball acadèmic centrat en la creació d’un videojoc funcional i publicable a GitHub Pages. La idea principal és aplicar conceptes bàsics de programació, disseny d’interfícies i lògica de joc a un projecte real, seguint una metodologia de recerca i desenvolupament.

El joc consisteix a localitzar i fer clic sobre personatges que apareixen als forats del tauler per obtenir punts. Cada tipus de personatge té un valor diferent, mentre que la bomba penalitza el jugador. La partida finalitza quan s’acaba el temps disponible.

## Objectiu acadèmic

- Dissenyar i desenvolupar un videojoc senzill des de zero.
- Aplicar coneixements de programació web i lògica de videojocs.
- Explorar l’ús d’assistents d’IA com a suport en la creació de codi.
- Documentar el procés de disseny, desenvolupament i proves del projecte.
- Publicar el resultat de manera accessible mitjançant GitHub Pages.

- index.html: punt d’entrada de l’aplicació.
- css/styles.css: estils visuals bàsics.

- specifications/: documentació tècnica i de disseny.
- README.md: informació general del projecte.
- LICENSE: llicència del projecte.

## Com executar el projecte

Per provar el joc localment, es recomana servir el projecte amb un servidor HTTP simple des de la carpeta arrel del repositori, per exemple:

```bash
python3 -m http.server 8123
```

Després, obre la pàgina al navegador des de l’URL local o des de l’URL pública del Codespace.

## Requisits

El projecte està pensat per executar-se en un navegador modern i es pot publicar fàcilment amb GitHub Pages sense necessitat de backend ni base de dades.
